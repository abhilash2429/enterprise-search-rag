# Decisions

| Date | Decision | Why |
|---|---|---|
| 2026-10-03 | Generator and judge: `openai.gpt-oss-120b` on Bedrock, `metrics_based_eval --no-correction`, reasoning effort medium | gpt-5.4 unaffordable or gated; one judge for every system keeps comparisons fair. Judge scores are compared only between my own systems. |
| 2026-10-03 | Paper BM25 reproduced with OpenSearch (harness settings verbatim) | Isolates generator and judge as the only differences. Recall@10 matched the paper at 68.4 in every question type. |
| 2026-10-03 | Hand-written BM25 runs over a sparse TF matrix with a tokenizer matching Lucene `standard` | Token-for-token identical to OpenSearch on 2,000 sampled docs. |
| 2026-10-03 | BM25 baseline run on all 500 questions | Untuned baseline, so no test leakage; matches the paper's reporting. |
| 2026-10-03 | Dense: Qwen3-Embedding-0.6B, full 1024 dims, paper chunking (512 cl100k tokens, 10% overlap, top-100 chunks to top-10 docs), model-card query instruction | Clean comparison against the paper's vector baseline; other chunkings are ablations. |
| 2026-10-03 | Embeddings computed on one EC2 g6.xlarge (vLLM), searched exactly on the laptop GPU | AWS credits; vLLM vectors verified equal to sentence-transformers (cosine ~1.000). |
| 2026-10-03 | Reranker: Qwen3-Reranker-0.6B | Same family as the embedder; fits the laptop GPU for dev runs. |
| 2026-10-03 | Tracing: Langfuse Cloud (free tier) via OpenTelemetry | No ops; demo can link to traces. |
| 2026-10-03 | Near-dup clustering: MinHash on text (word shingles + LSH); threshold picked from the measured distribution and inspected samples | Matches the stated job (copies differing in small facts); cheap, deterministic, explainable. |
| 2026-10-04 | Near-dup method switched to embedding similarity over doc vectors | MinHash found 1/722 gold docs with a near-dup; known version pairs have Jaccard 0.01-0.16 (results/neardup_minhash.md). Threshold tuned on dev-question pairs only. |
| 2026-10-04 | Dense baseline: recall@10 52.5 on all 500 (paper vector baseline 46.0) | Paper-faithful config; untuned, so run on all 500 like BM25. |
| 2026-10-04 | Embedding near-dups: mean pooling, cosine 0.88, flagged pairwise among the retrieved top-10 at query time; no corpus-wide clustering | 0.88 picked on dev labeled pairs (83% of versions, 5% of hard negatives). Union-find over corpus kNN chains topical neighbours into a 146K-doc cluster (results/neardup_embed.md). |
| 2026-10-04 | Own BM25 (bm25.py) replaces OpenSearch for runs: recall@10 68.3 vs 68.4 on all 500 | Same Lucene formula over exact doc lengths; residual gap is likely Lucene's lossy length norms. In-process, ~90 ms/query, no container. |
| 2026-10-04 | Hybrid: RRF over BM25 top-100 docs and dense top-100 docs (MaxP over top-4000 chunks), k=60 headline | Dev recall@10 67.6 vs BM25 63.6 (paired delta +4.0, 95% CI [-2.0, +9.9], n=141). k fixed at the paper value, sweep {10, 20, 60, 100} is an ablation (k=60 also best on dev). Fused top-100 holds 83.3% of dev gold, the reranker's ceiling. |
| 2026-10-04 | Reranker: Qwen3-Reranker-0.6B over the fused top-100, full doc capped at 4096 tokens, fixed custom instruction, pure rerank as headline; depths 20/50 and RRF(rerank, hybrid) as ablations | Dev recall@10 74.5 vs hybrid 67.6; RRF(rerank, hybrid) 77.7. Pointwise scores cached once for all 500, so depth ablations are offline re-sorts. fp16 not bf16: bf16 drifts up to 0.06 vs fp32 and creates spurious ties. |
| 2026-10-04 | Cited answerer: top-10 reranked docs numbered in context, [n] citation per claim, version-pair flags with latest-wins rule, LLM-decided abstention with a fixed refusal sentence | Judge sees the answer with markers stripped; document_ids = all context docs, same as the baselines. Harness-prompt run on the same retrieval kept as the baseline row. Reranker top score logged for a later abstention threshold. |
| 2026-10-04 | Kill test on dev passes with rerank + cited answerer: combined 57.9 vs BM25 42.2, paired +15.7 [+9.1, +22.3], 3 seeds | Threshold 55 met and CI excludes 0. Reranking alone with the harness prompt is +3.3 [-1.8, +8.3]; the answerer is +12.4 on the same retrieval, mostly completeness (correctness 68.7 to 70.2). Judge = generator = gpt-oss-120b, not leaderboard-comparable. Frontier-agent criterion not yet run. |
| 2026-10-04 | Headline stays pure rerank; RRF(rerank, hybrid) is an ablation | End to end it is +0.1 [-4.6, +4.9] vs pure rerank despite +3.2 recall@10. Pre-registered choice, simpler. |
| 2026-10-05 | Frontier file agent baseline: the harness's own bash agent (agent_retrieval.py, unmodified, 10-min cap) driven by gpt-6-luna, full dev, one seed; compared on score vs $/q, no cost matching | Agent 58.5 [51.3, 65.8] vs pipeline 57.9, paired +0.6 [-6.2, +7.9]: no detectable difference, so "does not lose" holds. Pipeline is 7.6x cheaper per question ($0.0028 vs $0.0214 generation) and reads 79x fewer input tokens (15.7K vs 1.25M mean). Agent p50 101 s, 5 of 150 hit the cap. Generators differ (luna vs gpt-oss-120b). |
| 2026-10-05 | Answerer context stays at 10 docs | 5 docs: -2.9 [-6.4, +0.4]; 20 docs: +1.4 [-2.6, +5.8] at 1.9x generation cost. Neither significant; 10 is the pre-registered value. |
| 2026-10-05 | Dense quantization: binary codes with fp16 rescore of a 4x oversampled shortlist is the low-memory config; int8 is lossless | Dev hybrid recall@10: fp16 67.6, int8 67.6 (1.58 GB), binary 63.2, binary + rescore 67.5 (197 MB in RAM, fp16 on disk). Headline keeps exact fp16 search; quantization is a deployment option. |
| 2026-10-05 | Reranker instruction stays custom | Model-card default instruction: recall@10 75.4 vs 74.5, +0.9 [-3.3, +5.2]. Instruction tuning buys nothing; kept the pre-registered one. |
| 2026-10-05 | Source router in the headline: gpt-oss (effort low) names 1-3 likely sources; BM25 and dense restricted to those sources join the RRF as two extra lists (soft boost), then rerank top-100 | Routing accuracy is weak (top-1 47.5%), and before reranking recall@10 drops 3.1, but routed candidates lift reranked recall@10 +3.1 [+0.8, +6.2] (semantic +8.1) and end to end +4.4 [+1.1, +7.7]: 62.2 vs 57.9, 3 seeds. Router prompt written once, not tuned on dev. ~$0.00007/q. Pure rerank becomes the no-router ablation. |
| 2026-10-05 | Chunking: headline keeps 512-token chunks with MaxP; whole-doc embedding (first 8192 tokens, 0.1% of docs truncated) is an equivalent, 3x smaller index | Dev hybrid recall@10 67.1 vs 67.6 (-0.5 [-4.3, +3.1]), recall@100 82.6 vs 83.3 (-0.7 [-3.5, +1.4]); dense alone +0.7 at 10, -1.1 at 100. 512K vectors / 1.05 GB vs 1.54M / 3.15 GB. Not run end to end since the reranker's input recall is unchanged. |
